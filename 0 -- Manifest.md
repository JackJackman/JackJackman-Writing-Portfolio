## [1 -- A Framework for Designing an AGILE Technical Debt Assessment](https://github.com/JackJackman/JackJackman-Writing-Portfolio/blob/main/1%20--%20A%20Framework%20for%20Designing%20an%20AGILE%20Technical%20Debt%20Assessment.md)

As a software developer at the Walton Institute, I authored a technical debt handbook that helped to improve the TD assessment process for my team. This method was applied and improved with regular use. In this piece, I aimed to translate that experience to apply to a more general audience.

As noted in the article, technical debt is a massive area of study, and much of the guidance that exists online is vague. This guide is intended for professional software developers looking for concise and actionable guidance.

I highlight the importance of creating and maintaining reliable documentation when performing repeatable processes in technical fields. I then identified maintainability as a valid starting point for technical debt management, and targeted signals that are tied to maintainability. The guidance was designed to be practical and easy to apply to the reader's individual circumstances.

**Skills & competencies:**
* Researched and communicated technical concepts for a general audience
* Applied software development experience to develop industry-specific documentation
* Authored in Markdown using Obsidian

The article is currently a work in progress, and the live draft was published on 9th November, 2026.

**AI disclosure:** No generative AI was used to write, edit, or polish any part of this article. The content in this article is entirely my own. ChatGPT was used to research additional background information. All facts were independently verified before submission.

## [2 -- Portfolio Instruction Booklet](https://github.com/JackJackman/JackJackman-Writing-Portfolio/blob/main/2%20--%20Portfolio%20Instruction%20Booklet.pdf)

This piece was created as part of an assignment for the postgraduate course in Technical Writing I am attending at the University of Limerick. In this assignment, I was presented with a poor example of instruction booklet and tasked with improving it. The assignment received an A1 grade, and this piece was used as an exemplar for the following year's assignment.

The instruction booklet was for a string of LED lights designed for residential use. The intended user is an average consumer who does not necessarily have any technical experience.

I rewrote the instructions so that they were sequential easy to follow. I clearly highlighted potential hazards involved with using this product, and linked them with their associated steps in the instruction procedure. I created a diagram of the device to help the user identify its components. Finally, I designed the booklet to be attractive and easy to use.

**Skills & competencies:**
* Instructional design including audience analysis
* Designed and formatted using Microsoft Word
* Diagram created using diagrams.net

This assignment was completed and submitted 8th December, 2025.

**AI disclosure:** No generative AI was used to create or polish any part of this piece.
